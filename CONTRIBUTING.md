# Contributing

Contributions are welcome from anyone: bug reports, fixes, new Forgejo features and docs.

- **Issues:** open one for a bug or an idea. Include your Forgejo version and what you expected to happen.
- **Pull requests:** fork, branch, and open a PR against `main`. Keep each PR to one change.
- **Before you open it:** run `pnpm install`, `pnpm test` and `pnpm build`. Add a test for any behaviour you change.
- **Questions:** use Discussions.

By contributing you agree that your work is released under the MIT licence of this repository.
